# NeoGaze Model Configs

MMPretrain configuration files for training gaze classifiers.

- `mobilevit-small_8xb128_in1k_singleclass.py`: MobileViT-Small (best performance)
- `resnet50_8xb32_in1k_singleclass.py`: ResNet-50 baseline
- `vit-base-p32_pt-64xb64_in1k_singelclass.py`: ViT-B/32 fine-tuned from CLIP

**Note:** Update `/path/to/neogaze/` placeholders to your local paths before training.
